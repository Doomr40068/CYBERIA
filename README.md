# Проект: сайт КИБЕРИЯ

## Установка и запуск

### 1. Установка backend

Перед началом необходимо установить и запустить backend через Docker.  
Инструкция находится в папке:

web-app-main

---

### 2. Установка frontend

Перейдите в папку my-app и установите зависимости:

npm install

---

### 3. Запуск проекта

После установки запустите проект согласно инструкции в файле:

my-app/README.md

---

## О проекте

В рамках проекта реализовано:

- Главная страница сайта
- Адаптивная верстка (мобильные устройства и ПК)
- Частично реализованный функционал
- Работа с API (все необходимые блоки получают данные с сервера)
- Интерфейс соответствует исходному дизайну

---

## Важно

- Проект реализован не полностью, выполнена основная часть главной страницы
- Некоторые элементы и функции находятся в стадии доработки

---

## Технологии

- Next.js
